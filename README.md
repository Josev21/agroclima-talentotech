# 🌱 AgroClima Info - Proyecto Talento Tech

Sitio web front-end de una sola página (Single Page Application) diseñado con temática "Agro-Green", enfocado en el monitoreo oficial del fenómeno **"El Niño"**, datos hidrometeorológicos del **Servicio Meteorológico Nacional (SMN)** y servicios de asesoramiento climático de precisión para el sector agropecuario argentino.

---

## 🚀 Características del Proyecto

- **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio mediante el uso de Flexbox y CSS Grid.
- **Paleta de Colores Agro-Green:** Combinación de tonos verdes institucionales (`#1b4332`, `#2d6a4f`, `#52b788`) y fondos claros inspirados en el sector agronómico.
- **Navegación Fluida:** Menú superior fijo (*sticky*) con desplazamiento suave (*smooth scroll*) y compensación de saltos de sección.
- **Contenido Multimedia:** Integración de reproductor de video de YouTube optimizado sobre el impacto climático.
- **Secciones Informativas:**
  - Banner principal con descripción e introducción al impacto de El Niño.
  - Noticias y reportes destacados sobre cultivos de invierno y verano.
  - Tarjetas de monitoreo de mapas de radar, pluviometría y pronósticos del SMN.
  - Análisis y opiniones de especialistas del sector.
- **Tienda de Servicios y Formulario Interactivo:**
  - Grilla de planes de asesoramiento y alertas hídricas (Reporte Básico, Monitoreo El Niño Pro y Consultoría Enterprise).
  - Selección dinámica de servicios que desplaza la pantalla al formulario de contratación.
  - Formulario interactivo con validaciones HTML5 y confirmación de suscripción.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Marcado semántico estructurado (`header`, `main`, `section`, `article`, `footer`, `form`).
- **CSS3:** Estilos avanzados, variables de diseño, Flexbox, CSS Grid, media queries para responsividad y efectos dinámicos (`hover`, transiciones y transformaciones).
- **Google Fonts:** Tipografías **Montserrat** (para títulos institucionales) y **Open Sans** (para legibilidad en párrafos).
